## Gotchas
- A Netlify scheduled function's URL answers **403** when the function is deployed and **200** (the SPA fallback) when it is missing: a quick check without the Netlify UI.
- Netlify's "Logs" for functions: `https://app.netlify.com/projects/taupe-capybara-0ff2ed/logs/functions`. Netlify does not post build statuses to GitHub commits on test pushes.
- PROD anon `articles?feed_id=eq.N` times out, and `articles.id` is not time-ordered. Use `created_at=gte.<timestamp>&order=created_at.desc`.
- GitHub's new fine-grained token screen uses "+ Add permissions" -> Actions; GitHub adds Metadata read-only automatically.
- Git Bash `TZ=America/Chicago date` silently prints UTC.
